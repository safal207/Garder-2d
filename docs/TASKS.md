# Garder-2d · реальная дорожная карта

## Версия 0.1 — первый игровой цикл

- [x] Конфигурация Godot 4.2 и 16:9-сцена.
- [x] Управление игроком (WASD/стрелки).
- [x] Появление врагов, движение к дереву и волны.
- [x] Удар игрока, очки, траты семян и простая ловушка.
- [x] Здоровье дерева, поражение и быстрый перезапуск.
- [x] Изолированные правила и базовые автотесты.
- [ ] Ручная проверка FPS и управления на реальном Windows/Linux ПК.
- [ ] Проверка сенсорного управления.

## Следующие небольшие учебные задачи

1. Добавить один новый тип противника с отдельной скоростью и видимым стилем.
2. Добавить восстанавливающее здоровье дерева улучшение с ценой в семенах.
3. Записать короткое видео игры с клавиатуры и игровой статистикой.
4. Добавить поддержку паузы, стартового меню и крупного HUD.
5. Добавить тесты границ ловушек и невозможности отрицательного здоровья.

## Пока не реализовано

- Кооператив и сетевой мультиплеер.
- Разные биомы, дерево навыков, полноценные сооружения и музыка.
- Выпуски в Steam/itch.io.
- Достижение стабильных 60 FPS на всех целевых устройствах.

Сравни с [концепцией GDD](GDD.md). Реальные результаты и изображение текущей сцены — в [README](../README.md).
